# プリセットスタジオ

### [最新バージョンをダウンロード](https://github.com/Dolphin-kun/PresetStudio/releases/latest)

## 概要
テキストのスタイル・フォント・エフェクト・場面切り替え・立ち絵の表情・テンプレートを、プレビューを見ながら選んで適用できるプラグインです。
よく使う見た目をプリセットとして保存しておけば、クリック 1 回やドラッグ＆ドロップで同じ見た目をすぐに再現できます。

## 使い方
画面左上のメニューバーから、`ツール` 内にある「プリセットスタジオ」を選択してください。
テキストプリセットは、アイテム編集パネルの「テキスト」の上にも一覧が表示されるので、ツールを開かなくても使えます。
この一覧が不要な場合は、ツールの「テキスト」タブにある「アイテム欄に表示」ボタンで非表示にできます。

### 基本操作

|操作|やり方|
|-|-|
|適用|一覧のプレビューをクリック|
|フォントとサイズ以外を適用|`Alt` を押しながらクリック|
|一部の項目だけ適用|右クリック →「部分的に適用」|
|タイムラインのアイテムに適用|プレビューをタイムラインのアイテムへドラッグ＆ドロップ|
|複数選択|`Ctrl` / `Shift` を押しながらクリック|
|プレビューの大きさを変更|一覧の上で `Ctrl` + マウスホイール|
|バリエーションを切り替え|プレビューの上で `Ctrl` + マウスホイール|
|表示するタブを選ぶ|タブの見出しを右クリック|

マウスを乗せると、エフェクトや場面切り替えの動きをアニメーションで確認できます。

## タブ一覧

|タブ|できること|
|-|-|
|テキスト|テキストのスタイル（フォント・色・装飾・配置・表示アニメーション・エフェクト）をプリセットとして保存し、適用します。|
|フォント|PC に入っているフォントを見本の文字で一覧表示します。お気に入り・カテゴリ・タグで整理できます。|
|エフェクト|映像エフェクト・音声エフェクトをプレビュー付きで一覧表示し、選択中のアイテムに追加します。|
|場面切り替え|場面切り替えをプレビュー付きで一覧表示します。ルール画像をその場で作ることもできます。|
|立ち絵|キャラクターの表情・立ち絵アイテムを保存し、クリックで適用します。表情の部品を選んで編集することもできます。|
|テンプレート|YMM4 のアイテムテンプレートをプレビュー付きで一覧表示し、追加します。|

### テキスト
タイムラインでテキストアイテムを選び、「追加」で今の見た目をプリセットとして保存します。
保存したプリセットは、フォルダ・カテゴリ・タグ・お気に入りで整理できます。

- **フォント / サイズを固定** : ツールバーのボタンをオンにしている間は、適用してもフォントとサイズを変えません。
- **バリエーション** : 同じカテゴリのプリセットは 1 つにまとまり、`Ctrl` + マウスホイールで切り替えられます。
- **プレビュー文字** : プリセットごと、または既定のプレビュー文字を右クリックメニューから変えられます。
- **適用できるアイテム** : テキストアイテムにはすべて、ボイスアイテムには字幕のスタイルが反映されます。図形・画像・立ち絵などには、プリセットのエフェクトだけが付きます。

### プリセットのリンク
プリセットを適用したアイテムは、そのプリセットとつながった状態になります。
アイテム編集パネルでアイテムを選ぶと、つながっているプリセットのプレビューが強調表示されます。

プリセットを「選択中のアイテムで上書き」すると、つながっているアイテムもまとめて更新するか確認します。
字幕のデザインを途中で変えたいときに、1 つずつ適用し直す必要がありません。

リンクはプロジェクトを開き直しても保たれます。YMM4 で分割したアイテムやコピーしたアイテムにも引き継がれます。

### テキストの分割
アイテム編集パネルの「テキスト」の上にあるはさみのボタンから、テキストを別々のアイテムに分割できます。
文字の位置を YMM4 の描画で測ってから配置するので、**見た目を変えずに**分割できます。

- **区切り位置で分割** : 文章の中で範囲を選んで区切りを追加します（`Enter` で追加、`Delete` で削除）。複数か所を一度に分割できます。
- **1文字ずつ / 1行ずつ** : 文字ごと・行ごとに分割します。
- **間隔** : 分けたアイテムの開始を、1 つごとに指定したフレームずつ遅らせます。

アイテム編集パネルのテキスト欄で範囲を選んでからプリセットをクリックすると、その部分だけを分割してプリセットを適用します。

### フォント
- **絞り込み** : お気に入り・日本語を表示できるフォント・明朝 / ゴシック（名前で判定）で絞り込めます。
- **検索** : 名前・カテゴリで検索できます。`#タグ` でタグ検索もできます。
- **整理** : 右クリックからカテゴリとタグを設定できます。タグはフォント名にマウスを乗せると表示されます。
- 見本の文字は、ツールバーの「テキスト」欄で変えられます。

### エフェクト
「映像エフェクト」と「音声エフェクト」のタブに分かれています。
ダブルクリックで、選択中のアイテムに追加します。

- **映像エフェクト** : プレビュー画像は自分の好きな画像に変えられます。
- **音声エフェクト** : クリックでエフェクトをかけた音を再生し、波形で違いを確認できます。プレビューの音声と音量はツールバーで変えられます。
- 選択中のアイテムに付いているエフェクトを、「追加」でテンプレートとして保存できます。

### 場面切り替え
すべての場面切り替えをプレビュー付きで確認できます。プレビューに使う切り替え前 / 切り替え後の画像も変えられます。

「ルール画像を作成」から、直線・円・時計回り・ブラインド・渦巻きなどの形を選んで、ルール画像をその場で作れます。
作ったルール画像は `<YMM4>\user\transition` に保存されます。

### 立ち絵
キャラクターを選ぶと、保存した表情と立ち絵アイテムが一覧で表示されます。
クリックすると、選択中の表情アイテム・ボイスアイテム・立ち絵アイテムにすぐ反映されます。

表情を選ぶと、下の欄に目・口・眉などの部品が並びます。部品をクリックすると、その場で表情を組み替えられます。
PSD 立ち絵・動く立ち絵に対応しています。

### テンプレート
YMM4 のアイテムテンプレートを一覧表示し、ダブルクリックで追加します。

- **入力項目** : 右クリック →「入力項目を設定」で、テンプレートを追加するときに入力したいテキストや色を選べます。
- **バックアップ** : 起動時にテンプレートのバックアップを取ります。テンプレートが消えたときは「バックアップから復元」で戻せます。
- **テキストプリセットに登録** : テンプレートの中のテキストを、テキストプリセットとして登録できます。
